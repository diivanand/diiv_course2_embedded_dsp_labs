# Course 3 — Computer Architecture & ARM Assembly

Coding-exercise workspace for [Course 3](https://www.diiv.io/course3/index.html): hands-on ARM64 (A64)
assembly on Apple Silicon, plus the Module 6 Cortex-M cross-disassembly work.

One folder per module (`m0/` … `m6/`), each with its own `Makefile`, `.s`/`.c` sources, and a
`notes.md` recording predicted vs. observed (register dumps, disassembly annotations, timings).

- m1 — Bits, logic, and arithmetic circuits · [exercises](https://www.diiv.io/course3/exercises-m1.html)
- m2 — ISA & microarchitecture · [exercises](https://www.diiv.io/course3/exercises-m2.html)
- m3 — A64 essentials · [exercises](https://www.diiv.io/course3/exercises-m3.html)
